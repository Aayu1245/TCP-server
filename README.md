## How To Run The Server
0. you can check the various features implemented in the update logs
1. quite simple, just clone the repo and run it locally in the same folder
2. you can use the multiple clients given, each with a different purpose to test the server
3. can use ctrl+c to quit the server
4. has a log file as well as the terminal to track whats going on currently
5. idle connections are automatically disconnected after 30s
6. client1 sends a single message, client2 sends in bytes at 1 sec interval, client3 sends multiple messages, client4 connects from 100 sockets, jsonclient sends various json requests
